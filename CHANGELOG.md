## v0.1.0 (2026-10-28)

### Highlights

- **New provider address.** This is the first release of SimplicityGuy's hard fork of
  [y0n0zawa/terraform-provider-resend](https://github.com/y0n0zawa/terraform-provider-resend). It is
  published as `SimplicityGuy/resend` on both registry.terraform.io and registry.opentofu.org:

  ```hcl
  terraform {
    required_providers {
      resend = {
        source = "SimplicityGuy/resend"
      }
    }
  }
  ```

- **Migrating from `y0n0zawa/resend`.** The fork is a separate provider address, so existing state
  needs a one-time switch, not just a version bump. Run the command for your CLI, then run
  `terraform init` or `tofu init` with the new `required_providers` source:

  ```sh
  terraform state replace-provider registry.terraform.io/y0n0zawa/resend registry.terraform.io/SimplicityGuy/resend
  tofu state replace-provider registry.opentofu.org/y0n0zawa/resend registry.opentofu.org/SimplicityGuy/resend
  ```

  The full migration guide (`docs/guides/migrating-from-y0n0zawa.md`) is planned for v1.0.0-rc.1 and
  is not part of this release.
- **resend-go v4.** The provider is built with `resend-go` v4.9.1.
- **Supported CLI versions.** Terraform 1.0.11 to 1.17.0 and OpenTofu 1.6.3 to 1.13.2. The oldest and
  latest version of each are the ones the project's checks run against; versions in between are
  expected to work but are not tested separately.
- **Signed releases.** The checksums file of every release is signed with the release key,
  fingerprint `30D2732FD215D0089C27FCCB9F85682D8BB841F1`. `terraform init` and `tofu init` verify the
  signature for you; to check a download by hand, follow
  [Verifying releases](https://github.com/SimplicityGuy/terraform-provider-resend#verifying-releases)
  in the README.
- **User-Agent.** Requests to the Resend API now identify the provider and the SDK, as
  `terraform-provider-resend/<provider version> resend-go/<resend-go version>`.
