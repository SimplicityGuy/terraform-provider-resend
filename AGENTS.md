# AGENTS.md

Instructions for AI coding agents working on the SimplicityGuy/resend Terraform/OpenTofu provider
(a hard fork of y0n0zawa/terraform-provider-resend). See [README.md](README.md) and
[CONTRIBUTING.md](CONTRIBUTING.md) for the human-facing version.

## Commands

Tools are pinned in `mise.toml`; `just --list` shows every recipe.

- `just check`: the pre-merge gate. It must pass before a change is submitted.
- `just test`, `just coverage`: unit tests and coverage. The project requires 100% coverage.
- `just docs`, `just docs-check`: regenerate and verify the registry docs. Never hand-edit `docs/`.
- `just testacc`: acceptance tests against the live Resend API. Needs `RESEND_API_KEY` for a
  dedicated test account; never run it against production.
- `just bump-preview`, `just bump`: release flow (maintainers only; see CONTRIBUTING.md).
- Do not run `just setup` inside a bead worktree: worktrees share the main clone's git hooks.

## Conventions

- Code comments and commit messages are in English.
- Commits follow Conventional Commits (Commitizen drives the version).
- Test first: write the test, see it fail, then implement.
- Do not edit `docs/` by hand, `CHANGELOG.md` (generated by Commitizen) or `mise.lock` (use `just lock`).

## Stack

Go, Terraform Plugin Framework (not the legacy SDKv2), protocol v6, `github.com/resend/resend-go`,
and `terraform-plugin-testing`. The provider must work under both Terraform and OpenTofu.

## Patterns

- **Retry:** wrap every Resend API call in `retryOnRateLimit` (`errors.go`); it backs off on HTTP 429
  and transient 500 errors.
- **404:** use `isNotFoundError(err)`. In `Read`, call `resp.State.RemoveResource(ctx)`; in `Delete`,
  return silently.
- **Immutable fields:** `stringplanmodifier.RequiresReplace()`, not SDKv2 `ForceNew`.
- **Schema:** computed-once fields use `UseStateForUnknown()`; enums use `stringvalidator.OneOf(...)`;
  defaults use `stringdefault.StaticString(...)` / `booldefault.StaticBool(...)`; model structs use
  `tfsdk:"field_name"` tags.
- **Resource shape:** interface assertion (`var _ resource.Resource = &myResource{}`), a
  `NewMyResource` constructor, a private struct holding `client *resend.Client`, a model struct, the
  methods `Metadata`, `Schema`, `Configure`, `Create`, `Read`, `Update`, `Delete`, and import via
  `ImportStatePassthroughID`.
- **Configure:** take `*resend.Client` from `req.ProviderData`; return early when it is nil and add a
  diagnostic when the type is wrong.
- **Errors:** `resp.Diagnostics.AddError("Error <action> <resource>", detail)`, with the resource
  identifier and the original error in the detail.

## Testing

- Unit tests (`*_unit_test.go`) use the mock client in `mock_test.go` and never touch the network.
- Acceptance tests are named `TestAcc<Resource>_<scenario>`, use `testAccProtoV6ProviderFactories`,
  call `testAccPreCheck` (requires `RESEND_API_KEY`) and name resources with the `tf-test-` prefix
  (`acctest.RandStringFromCharSet` for uniqueness) so the sweepers in `sweep_test.go` can clean up.

## AGF — Agentic Git Flow

This repo is onboarded as a **`bh` hive** and develops via **AGF**: work is tracked in beads
and driven through `bh`, **not** raw `git` / `bd` / `gh`.

- **Is this repo set up for AGF?** → run `bh hive ready` (add `-v` for the line-item breakdown).
- **Lifecycle, roles, conventions:** see `docs/AGF.md` and the bh plugin's role skills.
- Drive beads with `bh work`; load the role skill for your seat (coordinator / developer / merger).
- Batch/collapsed work lives in ONE shared `wt/batch/<group>` worktree and completes as a UNIT:
  `bh work submit --group` then `bh work merge --group` — per-bead `submit`/`check` don't apply.
