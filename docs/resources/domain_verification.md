# resend_domain_verification (Resource)

Asks Resend to verify a domain's DNS records. Creating the resource sends one verification request and records the domain's status; it does not wait for verification to finish, and Resend keeps checking in the background. Publish the domain's `records` first (make this resource depend on your DNS records), or the check starts before the records exist. Destroying the resource only removes it from state: a verification can't be undone.

`status` is read from Resend on every refresh, so `terraform apply -refresh-only` (or
`tofu apply -refresh-only`) picks up the result once Resend finishes checking. To send a
new verification request, for example after fixing a DNS record, replace the resource:
`terraform apply -replace=resend_domain_verification.example`.

## Example Usage

```terraform
resource "resend_domain" "example" {
  name = "updates.example.com"
}

# Publish resend_domain.example.records with your DNS provider first and add
# those records to depends_on, so verification starts after they exist.
resource "resend_domain_verification" "example" {
  domain_id = resend_domain.example.id
}

output "domain_status" {
  value = resend_domain_verification.example.status
}
```

For a complete flow that publishes the records with Cloudflare before verifying, see the
Cloudflare example on the `resend_domain` resource page.

## Schema

### Required

- `domain_id` (String) The ID of the domain to verify, usually `resend_domain.<name>.id`. Changing it replaces the resource, which sends a new verification request.

### Read-Only

- `status` (String) The domain's verification status, refreshed on every read: one of `not_started`, `pending`, `verified`, `partially_verified`, `partially_failed`, `failed` or `temporary_failure`.

## Import

Import is not supported. This resource stands for a verification request rather than an
object in Resend, so there is nothing to import. To bring an existing domain's verification
under management, declare the resource and apply: that sends one verification request and
records the domain's current status.
