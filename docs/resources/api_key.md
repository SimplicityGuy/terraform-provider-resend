# resend_api_key (Resource)

Manages a Resend API key. Resend shows a key's token only once, when the key is created, and the provider keeps it in state as the sensitive `token` attribute. Changing any argument replaces the key, which issues a new token.

~> **The token is stored in state.** Anyone who can read your state can read `token`. Use
an encrypted remote backend (or OpenTofu state encryption) and restrict who can read it.

## Example Usage

```terraform
# A key that can manage every resource in the Resend team.
resource "resend_api_key" "admin" {
  name = "terraform-admin"
}

# A key that can only send email, and only from one domain.
resource "resend_domain" "example" {
  name = "updates.example.com"
}

resource "resend_api_key" "sending" {
  name       = "app-sending"
  permission = "sending_access"
  domain_id  = resend_domain.example.id
}

# The token is only available here, right after the key is created. Hand it to
# whatever needs it (a secret store, an application's configuration).
output "sending_api_key" {
  value     = resend_api_key.sending.token
  sensitive = true
}
```

To rotate a key, replace it: `terraform apply -replace=resend_api_key.sending` (or
`tofu apply -replace=resend_api_key.sending`) deletes the old key and creates a new key
with a new token.

## Schema

### Required

- `name` (String) The name of the API key, shown in the Resend dashboard. Changing it replaces the key.

### Optional

- `domain_id` (String) Restricts the key to sending from one domain, by domain ID. Resend only applies it when `permission` is `sending_access`. Changing it replaces the key.
- `permission` (String) What the key may do. `full_access` can create, read, update and delete any resource; `sending_access` can only send email. Valid values: `full_access`, `sending_access`. Defaults to `full_access`. Changing it replaces the key.

### Read-Only

- `id` (String) The Resend API key ID, a UUID. This is not the secret token.
- `token` (String, Sensitive) The secret API key (`re_...`). Resend returns it only when the key is created, so it is empty for an imported key and can't be recovered if lost from state.

## Import

Import an API key by its Resend API key ID, not by its `re_...` token.

In Terraform v1.5.0 and later, and OpenTofu v1.5.0 and later, use an
[`import` block](https://developer.hashicorp.com/terraform/language/import):

```terraform
import {
  to = resend_api_key.sending
  id = "dacf4072-4119-4d88-932f-6202748ac7c8"
}
```

Or use the `terraform import` (or `tofu import`) command:

```shell
# Import an API key by its Resend API key ID (not the re_... token).
terraform import resend_api_key.sending dacf4072-4119-4d88-932f-6202748ac7c8
```

~> **An imported key is replaced on the next apply.** Resend returns only a key's ID, name
and creation time, so the token, `permission` and `domain_id` aren't filled in on import.
Because changing `permission` or `domain_id` replaces the key, the next plan destroys the
imported key and creates a new one with a new token. Only import a key you are ready to
rotate.
